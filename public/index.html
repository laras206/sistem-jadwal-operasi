Sistem Informasi Jadwal Operasi Pasien
Berbasis Web dengan QR Code

Website ini membantu pasien RS Sehat Sentosa melihat informasi jadwal operasi dengan cepat dan aman. Pasien dapat memeriksa jadwal operasinya sendiri menggunakan kode akses, memindai QR Code untuk membuka halaman jadwal, dan admin dapat mengelola seluruh jadwal operasi.

Petunjuk Penggunaan Website

Ikuti langkah-langkah berikut untuk menggunakan sistem ini

1
📂

Lihat Jadwal Operasi

Buka halaman Daftar Jadwal untuk melihat jadwal operasi yang aman dipublikasikan. Anda dapat memfilter berdasarkan tanggal dan ruang operasi.

2
🔍

Cek Jadwal Pribadi

Buka halaman Cek Jadwal Saya, masukkan kode akses pasien (contoh: PAS-2024-001) untuk melihat jadwal operasi Anda sendiri.

3
📷

Scan QR Code

Buka halaman Scan QR Code dan arahkan kamera HP ke QR Code yang dipasang di rumah sakit untuk langsung menuju halaman jadwal.

4
🔐

Login Admin

Untuk petugas rumah sakit, login melalui halaman Admin menggunakan username admin dan password admin123.

Fitur Utama Sistem

Beberapa fitur yang tersedia dalam sistem informasi ini

📊

Dashboard Admin

Statistik real-time jumlah jadwal operasi, jadwal hari ini, jadwal mendatang, dan jadwal yang ditunda. Memudahkan petugas memantau operasional.

📅

Kelola Jadwal

Admin dapat menambah, mengubah, menghapus, dan mengubah status jadwal operasi. Sistem mencegah bentrok ruang operasi secara otomatis.

🔒

Akses Aman

Pasien hanya bisa melihat jadwalnya sendiri menggunakan kode akses rahasia. Data sensitif tidak ditampilkan di halaman publik.

🔒

Integrasi QR Code

QR Code berisi URL halaman jadwal. Pasien dapat memindai dengan kamera HP untuk langsung membuka halaman jadwal operasi.

📄

Laporan

Admin dapat mencetak laporan jadwal operasi atau mengunduh dalam format CSV untuk diolah lebih lanjut di Excel.

🔒

Keamanan Dasar

Password admin disimpan dalam bentuk hash (bukan teks biasa). Halaman admin dilindungi session. Validasi input diterapkan di setiap form.

⚠ Peringatan Penting: Website ini merupakan prototipe akademik yang dibuat untuk keperluan UAS mata kuliah Rekayasa Perangkat Lunak. Seluruh data pasien dan jadwal operasi yang ditampilkan adalah data fiktif. Sistem ini belum lulus uji keamanan dan tidak boleh digunakan untuk menyimpan data pasien nyata atau untuk pelayanan klinis.
