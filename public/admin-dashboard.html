Pengaturan Aplikasi

🌐 URL Website (untuk QR Code)

URL ini digunakan untuk membuat QR Code. Saat di-scan, QR Code akan membuka URL ini.
Saat pengembangan: gunakan http://localhost:3000.
Saat sudah di-hosting: ganti dengan URL publik, mis. https://jadwal-rs.example.com.

⚠ Peringatan Keamanan

Sistem ini merupakan prototipe akademik dengan keterbatasan keamanan:

  • Password demo menggunakan password lemah (admin123).
  • Session secret masih hardcoded di source code.
  • Belum menerapkan HTTPS secara default (perlu reverse proxy).
  • Belum ada audit log untuk aktivitas admin.
  • Rate limiting belum diterapkan pada endpoint login.

Jangan gunakan prototipe ini untuk menyimpan data pasien nyata tanpa pengujian keamanan lebih lanjut oleh profesional.
