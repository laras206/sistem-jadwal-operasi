Scan QR Code

Arahkan kamera ke QR Code yang terpasang di area rumah sakit untuk membuka halaman jadwal

📷 Pindai QR Code

Klik tombol "Mulai Kamera" di bawah, lalu arahkan kamera HP atau laptop ke QR Code yang ingin Anda pindai.

Kamera belum diaktifkan.

ℹ Tentang QR Code

QR Code di sistem ini berisi URL halaman website, bukan teks biasa. Setelah dipindai, browser HP akan otomatis membuka halaman jadwal operasi.

Cara Menggunakan:

  1. Klik tombol "Mulai Kamera".
  2. Izinkan akses kamera saat browser meminta.
  3. Arahkan kamera ke QR Code pada jarak 10-20 cm.
  4. Tunggu hingga QR Code terdeteksi otomatis.
  5. Browser akan otomatis mengarahkan ke halaman yang dituju.

Alternatif:

Jika kamera tidak berfungsi, Anda juga bisa memindai QR Code menggunakan:

  • Aplikasi Kamera bawaan HP (sebagian besar HP modern mendukung).
  • Aplikasi pemindai QR pihak ketiga dari Play Store / App Store.
⚠ Catatan: Kamera memerlukan izin browser. Pastikan Anda mengakses halaman ini via https:// atau http://localhost. Jika diakses dari HP, gunakan IP laptop (mis. http://192.168.x.x:3000) pada WiFi yang sama.
